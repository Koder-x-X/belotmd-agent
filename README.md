# belotmd_agent

Стол и агенты для игры на [belot.md](https://belot.md).

За основу взят публичный SDK **[belotmd](https://github.com/MrUnBaiat/belotmd)** (MrUnBaiat, лицензия MIT, copyright Cristian, 2026): протокол сайта, правила, восстановление состояния и мост Colyseus. Эта сборка добавляет локальный стол, агент `fallen3` и разбор своих партий.

Логины и пароли профилей в репозиторий не входят. Их вводят в столе на своём компьютере, файлы с ними остаются только локально.

## Что нужно

- Python 3.9 или новее
- Node.js 18 или новее и npm

Стол на троих играет кодом из этой папки. Стол на четверых ищет соседнюю папку `belotmd` (тот же SDK, клон [репозитория-основы](https://github.com/MrUnBaiat/belotmd)).

## Установка

```powershell
cd belotmd_agent
python -m pip install -e ".[dev]"
npm install
copy .env.example .env
```

`.env` нужен только боту из командной строки: туда вставляются cookies `PHPSESSID` и `token` из браузера. Файл в git не попадает.

Для стола cookies не нужны. Логин и пароль вводятся в форме и пишутся в локальный `desk/profiles.json`.

## Запуск стола

```powershell
cd belotmd_agent\desk
python server.py
```

Откройте http://127.0.0.1:8790/ — только с этого компьютера.

1. Введите логин, пароль и агента и посадите бота. Сейчас линия агентов — `fallen3` (`desk/LATEST_AGENT`).
2. Вкладка **Учение**: три уже сохранённых профиля, кнопка **Сесть втроём**. Пароль приватного стола можно оставить пустым — стол сам его придумает.
3. Если закрыть стол и запустить его снова, боты из локального `desk/session.json` садятся сами.

Один бот без стола, с cookies в `.env`:

```powershell
cd belotmd_agent
python play.py --agent fallen3
```

Список агентов: `python play.py --list-agents`. В комплекте есть `fallen3`, `fallen2`, `fallen`, `strong`, `strong2`, `heuristic`, `random`.

## Как отключить

**Один бот.** На карточке бота кнопка **Остановить после партии**. Он доигрывает текущую партию и выходит, и из автозапуска его убирает. Пока партия идёт, **Включить** или **Отмена** возвращает его в игру.

**Трио.** На вкладке **Учение** кнопка **Остановить трио**. Тоже доигрывают текущую партию.

**Весь стол.** В окне, где запущен `python server.py`, нажмите Ctrl+C. Процессы ботов останавливаются сразу. Список автозапуска при этом не стирается: следующий запуск стола снова посадит тех же ботов.

Чтобы после перезапуска никто не садился, сначала нажмите **Остановить после партии** у каждого бота и дождитесь, пока он выйдет. Только потом закрывайте стол.

## Что не коммитить

| Файл | Зачем он на диске |
|---|---|
| `desk/profiles.json` | логины и пароли профилей |
| `desk/session.json` | кого сажать после перезапуска стола, тоже с паролями |
| `.env` | cookies аккаунта для запуска из консоли |
| `desk/admin.token` | вход в раздел истории |
| `desk/history/`, `data/journals/` | записи партий и чужие ники |

Пустой образец полей профиля, без настоящих данных: `desk/profiles.example.json`.
