# Стол belotmd_agent

Тот же интерфейс, что у `web_belotmd`, плюс:

- выбор **агента на профиль** (логин A → strong, логин B → heuristic, …);
- вкладка **Статистика → сравнение агентов** (победы, поражения, % побед).

Порт **8790** (старый стол остаётся на 8787).

Профили (логин/пароль/агент) пишутся в локальный `profiles.json`
(в git не попадает). В форме выбираете сохранённый профиль или вводите новый.

## Запуск

```powershell
cd belotmd_agent\desk
python server.py
```

Откройте http://127.0.0.1:8790/

- **На троих** → сборка `belotmd_agent` (strong / heuristic / random)
- **На четверых** → соседняя папка `belotmd` (если есть)

Cookies в браузер не отдаются. Только localhost.

## История и опыт

Вкладка **История** (`#/history`): запись матчей по ботам, ручная сборка
опыта, скачивание сборников. Подробности: [`docs/history-experience.md`](../docs/history-experience.md).

Доступ локальный (`127.0.0.1`) — отдельный токен не нужен.
